# Telegram-бот для приёма заявок

Бот задаёт клиенту три вопроса — имя, телефон, задача — сохраняет заявку в CSV и присылает уведомление владельцу в Telegram.

Работает на чистом Python: **ни одной сторонней библиотеки**, только стандартная. Нечего устанавливать и нечему ломаться при обновлении.

## Что умеет

- диалог из трёх шагов с валидацией (имя, телефон, задача);
- запись заявки в `leads.csv` — открывается в Excel;
- уведомление владельцу о новой заявке;
- команды `/start`, `/cancel`, `/myid`, `/help`;
- лог в `log.txt`, чтобы было видно, что произошло.

## Стек

- Python 3 (стандартная библиотека: `urllib`, `csv`, `json`);
- Telegram Bot API, long polling — без вебхуков и сервера;
- запуск одной кнопкой на Windows (`запустить.bat`).

## Быстрый старт

1. Получите токен у [@BotFather](https://t.me/BotFather): `/newbot`.
2. Скопируйте `config.example.txt` → `config.txt` и вставьте токен:

   ```ini
   TOKEN=123456789:AA...
   OWNER_ID=
   ```

3. Запустите:

   ```bash
   python bot.py
   ```

4. Напишите боту `/myid` — он пришлёт ваш ID, впишите его в `OWNER_ID`.
5. Перезапустите и оставьте тестовую заявку.

## Безопасность

`config.txt` содержит токен бота — он в `.gitignore` и **не должен** попадать в репозиторий. Если токен утёк, перевыпустите его в `/revoke` у BotFather.
